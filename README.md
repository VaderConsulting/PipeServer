# PipeServer

Desaware VB6 Named Pipe Server (`PIPESRV.exe`, © 1997): creates `\\.\pipe\vbpgpipe1` and waits for a client (`ConnectNamedPipe`), then sends blocked or async data. Open `Pipesrv.vbp` in the VB6 IDE (pair with PipeClient).
